# `mephi-18kpu`

`mephi-18kpu` — организация с учебными репозиториями курсов. Здесь размещаются материалы преподавателей, задания и предусмотренные учебным процессом рабочие пространства студентов.

## Начало работы

### Студентам

Откройте репозиторий своего курса, прочитайте его `README.md` и следуйте [общим инструкциям для студентов](https://github.com/mephi-18kpu/common-manuals#инструкции-для-студентов). Дополнительные указания преподавателя конкретного курса имеют приоритет.

### Преподавателям

Порядок подготовки и ведения курса описан в [общих инструкциях для преподавателей](https://github.com/mephi-18kpu/common-manuals#инструкции-для-преподавателей). Для создания нового репозитория или изменения административных настроек обратитесь к владельцам организации.

### AI-агентам

Перед работой необходимо прочитать [`common-manuals/AGENTS.md`](https://github.com/mephi-18kpu/common-manuals/blob/master/AGENTS.md), а затем локальные инструкции целевого репозитория.

## Основные репозитории

- [`common-manuals`](https://github.com/mephi-18kpu/common-manuals) — общие правила работы для студентов, преподавателей и AI-агентов.
- [`course-template`](https://github.com/mephi-18kpu/course-template) — шаблон учебного репозитория курса.

## Основные принципы

- Каждый курс ведётся в отдельном репозитории.
- Материалы преподавателей и работы студентов разделяются установленной структурой веток и директорий.
- Правила конкретного курса дополняют общие инструкции организации.
- Персональные данные и действующие секреты не публикуются в учебных репозиториях.
- Административные настройки изменяют только владельцы организации.

## Помощь

Маршрутизация учебных, технических и административных вопросов описана в [`SUPPORT.md`](../SUPPORT.md).
