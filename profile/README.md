# `mephi-18kpu`

`mephi-18kpu` — организация с учебными репозиториями курсов. Здесь размещаются материалы преподавателей, задания и предусмотренные учебным процессом рабочие пространства студентов.

## Основные принципы

- Каждый курс ведётся в отдельном репозитории.
- Материалы преподавателей и работы студентов разделяются установленной структурой веток и директорий.
- Правила конкретного курса дополняют общие инструкции организации.
- Персональные данные и действующие секреты не публикуются в учебных репозиториях.
- Административные настройки изменяют только владельцы организации.
