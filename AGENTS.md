# Инструкции для AI-агентов

Эти правила распространяются на работу AI-агентов с публичным репозиторием `.github` организации [`mephi-18kpu`](https://github.com/mephi-18kpu).

## Порядок работы

1. Перед началом работы прочитайте актуальный [`common-manuals/AGENTS.md`](https://github.com/mephi-18kpu/common-manuals/blob/master/AGENTS.md).
2. При работе с конкретным учебным репозиторием дополнительно прочитайте его `README.md`, локальный `AGENTS.md` и применимые инструкции курса.
3. Если локальные правила конкретного репозитория уточняют общие инструкции, соблюдайте локальные правила в пределах их области действия.

## Границы действий

- Не создавайте, не изменяйте и не удаляйте файлы без явной просьбы пользователя.
- Не выполняйте изменяющие Git-команды и не меняйте состояние GitHub без отдельного явного разрешения.
- Архитектурные, организационные и методические решения сначала обсуждайте с пользователем; предлагайте конкретные варианты, преимущества и недостатки.
- Не переносите в этот публичный репозиторий приватные административные инструкции, персональные данные, токены, приватные ключи, коды двухфакторной аутентификации и другие действующие секреты.
- Не открывайте и не анализируйте закрытые реестры идентичностей и учётных данных организации.
- Отвечайте по-русски, если пользователь явно не попросил использовать другой язык.

## Работа с файлами

- Вносите только минимальные изменения, необходимые для выполнения запроса.
- Сохраняйте несвязанные изменения пользователя.
- Используйте UTF-8 без BOM.
- В Markdown не создавайте ручные переносы строк внутри абзацев и отдельных элементов списков.
- Подробные учебные правила храните в `common-manuals`, правила конкретного курса — в его репозитории, а административные процедуры — в предназначенном для них приватном источнике.
