# Общие файлы организации `mephi-18kpu`

Этот публичный репозиторий содержит профиль организации и общие community-файлы GitHub для репозиториев организации [`mephi-18kpu`](https://github.com/mephi-18kpu).

## Состав

- [`profile/README.md`](profile/README.md) — публичное описание организации, отображаемое на её главной странице.
- [`AGENTS.md`](AGENTS.md) — общие правила для AI-агентов, работающих с этим репозиторием.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — единая точка входа для студентов, преподавателей и других участников.
- [`SUPPORT.md`](SUPPORT.md) — маршрутизация учебных, технических и административных вопросов.

GitHub использует поддерживаемые community-файлы из этого репозитория как значения по умолчанию для репозиториев организации, в которых нет собственных файлов соответствующего типа. Локальные инструкции конкретного репозитория или курса имеют приоритет.

## Основные источники правил

- [`common-manuals`](https://github.com/mephi-18kpu/common-manuals) — общие инструкции для студентов, преподавателей и AI-агентов.
- [`course-template`](https://github.com/mephi-18kpu/course-template) — шаблон новых учебных репозиториев.

Подробные правила курсов и административные процедуры не дублируются в этом репозитории. Их следует изменять в соответствующем первичном источнике.
